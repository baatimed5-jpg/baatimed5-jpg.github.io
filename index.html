AegisMCP: a security gateway for LLM agents

A gateway between AI agents and their tools (Model Context Protocol). Every tool call goes through PII masking, a fine-tuned DeBERTa prompt-injection detector, human approval for risky actions, and a context optimizer that cuts tokens by 79%.
